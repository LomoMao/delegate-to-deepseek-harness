# Contributing

Thanks for taking a look.

This repo is deliberately small, so the best contributions are usually small too: clearer routing rules, safer setup defaults, compatibility fixes, or a reproducible edge case.

Before opening a PR:

1. Keep the skill focused on Codex → DeepSeek Harness delegation.
2. Avoid adding a new dependency when a short instruction or shell script will do.
3. Run `./scripts/validate.sh`.
4. If behavior changes, add a short note to `CHANGELOG.md`.

Please do not include API keys, private prompts, customer code, or copied proprietary material in issues or tests.

For larger design changes, opening an issue first is usually easier than sending a large PR cold.
